# 사이언스 뿌요 팡! 🟣🟡🔴

3학년 2학기 과학 **3단원 〈소리의 성질〉**을 차시별로 복습하는 **연결 퍼즐 대전 게임**이에요.
「잉글리시 뿌요 팡!」의 구조·디자인·랭킹을 그대로 쓰고, 문제와 화면만 과학판으로 바꿨어요.
과학 문제를 맞히면 뿌요 한 쌍을 받고, 같은 색 4개를 이어 터뜨리고, 2연쇄부터 상대에게 방해 뿌요를 보내요.

## 주소
- 학생: `https://(주소)/` — 입장 코드 4자리 + 별명
- 교사: `https://(주소)/teacher.html` — 비밀번호는 잉글리시 뿌요 팡과 같아요 (Render 환경변수 `TEACHER_PASSWORD`로 바꿀 수 있어요)

## 반
- **3학년 1반~7반**이 처음부터 만들어져 있어요. 입장 코드는 **0301 ~ 0307**로 고정이라 서버가 다시 켜져도 바뀌지 않아요.
- 교사 화면의 입장 코드 옆 QR을 찍으면 코드가 채워진 채로 들어와요.

## 대결 방식 (교사 관리 → 경기 설정 → 대결 방식)
| 방식 | 설명 |
|---|---|
| **1인(AI)** | 들어온 학생마다 바로 AI 친구와 1:1. 기다리는 학생이 없어요 |
| **2인전** | 2명씩 자동으로 짝. 짝이 없으면 8초 뒤 AI와 대결 |
| **3인전** | 3명씩 자동으로 묶어요. 모자라면 AI가 채워요 |

AI전도 똑같이 랭킹 점수에 들어가요. 랭킹전(1:1 도전)과 데스매치도 영어판과 똑같이 쓸 수 있어요.

- **3단원 전체**: 94문제 모두
- **차시 고르기**: 아래 차시 중 하나 또는 여러 개 (예: 2·3차시만)

|---|---|---|
| 1 | 소리는 어떻게 날까? | 11 |
| 2 | 큰 소리와 작은 소리 | 10 |

## 3학년 쉬운 모드 (처음부터 켜져 있어요)
교사 관리 → 세부 설정 → **3학년 쉬운 모드**에서 반마다 켜고 꺼요. 켜져 있으면 반 이름 옆에 🐣 쉬운 모드가 보여요.
- 뿌요 놓기 버튼이 **큰 버튼 4개**(◀ 왼쪽 · ↻ 돌리기 · ⬇ 놓기 · ▶ 오른쪽)로 바뀌어요. 판의 칸을 눌러 옮길 수도 있어요.
- 조작을 헷갈리게 하는 **안개·뒤죽박죽 이벤트가 나오지 않아요**. (방해 폭탄·과학왕·황금 문제·피버 타임은 그대로)
- AI가 문제를 더 천천히 풀고, 뿌요도 덜 잘 쌓아요.
- 새 반의 기본 색 수는 **3색**이에요(4개 잇기가 쉬워요). 익숙해지면 4색으로 올리세요.

## 3학년용으로 바꾼 것
- 문제를 푸는 동안 가운데가 **사진 + 큰 글씨 문제 + 큰 보기 4개(①②③④)**로 바뀌어요. 사진을 누르면 크게 보여요.
- 처음 틀리면 틀린 보기 2개를 지워 **둘 중에서** 고르게 하고, 두 번째에 정답을 알려 줘요. 다시 맞혀도 뿌요를 받아요.
- 맞히면 정답과 **설명**을 2초쯤 보여 준 뒤 뿌요를 놓아요.
- AI는 3학년 속도에 맞춰 문제를 천천히 풀어요.
- 틀린 문제는 3문제 뒤에 한 번 더 나오고, 경기가 끝나면 **오답 복습**에서 사진과 설명을 다시 볼 수 있어요.

## 랭킹 (그대로)
- **랭킹 점수** = 첫 시도 정답 3점 + 재도전 정답 1점 + 순위 점수(1등 20 · 3인전 2등 8 · 그 밖 3)
- 우리 반 / 학년 전체 / 반 대항전, TV 모드, 칭호(연쇄왕·정확왕·복습왕 등), 기록 엑셀 내려받기

## 이벤트 (그대로, 영어왕 → 과학왕)
안개(3연속) · 뒤죽박죽(5연속) · 방해 폭탄(7연속) · 👑 과학왕(10연속) · 방어막 · 황금 문제 · 피버 타임 · 막판 스퍼트 · 역전 찬스

## 문제 바꾸기
교사 화면 → **문제 관리**에서 차시별로 보고 켜고 끌 수 있어요. 새 문제는 **양식 받기** → 엑셀에 적어서 **문제 올리기**.
양식: `차시(1~9) | 유형(비워 두기) | 문제 | 정답 | 오답1 | 오답2 | 오답3 | 설명`

## 실행·배포
```
npm install
npm start            # http://localhost:3000
npm test             # 가상 학생 자동 대결 시험 (npm i --no-save socket.io-client 먼저)
```
Render: New → Web Service → 이 저장소 → Build `npm install`, Start `npm start`, Region Singapore, Free.
(잉글리시 뿌요 팡과 서버를 따로 두어야 기록이 섞이지 않아요.)

## 기록 지키기
Render 무료 서버는 한동안 쓰지 않으면 잠들고, 깨어날 때 저장 파일이 지워질 수 있어요.
교사 화면이 1분마다 기록을 그 컴퓨터 브라우저에 자동 백업하고, 서버가 비어 있으면 로그인할 때 되살릴지 물어봐요.
